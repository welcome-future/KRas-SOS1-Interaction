# KRas-SOS1-Interaction
This document contains the information related to building a KRas·SOS1·KRas ternary complex for molecular dynamic simulations. There are nine branches:
1. the main branch includes:
   1.1. the input files for molecular dynamic (MD) simulation.
   1.2. the input file for MM/GBSA calculation.
   
2. The KRasGTP_GEFs_BI3406 folder includes:
   2.1. the inintial structure of the wild type BI-3406·(KRasGTP·Mg2+)·SOS1·(KRasGTP·Mg2+) quaternary complex.
   2.2. all kinds of RMSD values evolving with the simulation time (figure1b). 
   2.3. the distance from the interactional network of mg2+ ion (figure1d). 
   2.4. the pairwise distance calculated from last 200-ns trajectories (figure 3a).
   2.5. the distance of the important hydrogen bonds (figure 3d). 
   2.6. the distance of the important salt bridges (figure 4).
   2.7. the representative structure for showing the interactions (figure 3b, figure 3c, figure6) and calculating the electrostatic potential energy surface (figure 8).
   2.8. the results from MM/GBSA calculation (figure 7).
